# Support & Questions

AetherOS-Showcase is a research/documentation repository rather than a packaged end-user operating system distribution.

## Use GitHub issues for

- documentation questions;
- benchmark interpretation;
- architecture clarification;
- reproducibility questions about published evidence;
- broken links / formatting;
- research discussion that belongs in public.

## Do not use public issues for

- private kernel source requests framed as security reports;
- credentials or private logs;
- vulnerability details that require coordinated disclosure;
- claims about unpublished rounds without supporting evidence.
