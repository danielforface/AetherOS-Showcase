# Security Policy

## Supported public surface

This repository contains public documentation and selected architecture/proof material. The complete AetherOS kernel is not published here.

## Reporting a vulnerability

Please **do not disclose sensitive vulnerabilities in a public issue** if the report could expose exploit details affecting the private kernel, boot chain, device drivers, GPU command submission, DMA handling or memory-management implementation.

Because this repository currently has no dedicated public security mailbox declared in its metadata, use a private contact channel associated with the repository owner before publishing details. If no private contact channel is available, open a minimal issue requesting a private security contact **without including exploit details**.

## Documentation-only issues

Incorrect documentation, stale claims, accidental information disclosure and unsafe reproduction instructions may be reported through the normal issue templates.

## Scope note

AetherOS is an active research system and is not currently represented as a hardened multi-user production operating system.
